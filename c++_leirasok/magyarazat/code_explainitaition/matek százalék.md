

------

## Amit csináltál

```
800 ÷ 100 = 8
8 × 30 = 240        ← ez az új betegek száma ✓
800 + 240 = 1040    ← ez az összeg ✓
```

------

## De itt a hiba!

Az 1040-et **nem kell 100-zal osztani!**

Az 1040 már **maga a végeredmény!**

```
800 + 240 = 1040 beteg az 1. nap végén  ✓
```

------

## A szorzó így jön ki

```
100 + 30 = 130 ÷ 100 = 1.30
```

Tehát:

```
800 × 1.30 = 1040  ✓
```

------

## Mindkét út ugyanoda vezet

```
800 + 240      = 1040  ✓
800 × 1.30     = 1040  ✓
```
