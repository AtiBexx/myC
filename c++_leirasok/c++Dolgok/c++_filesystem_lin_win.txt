# Még jobb módszer (amit ajánlok) ⭐

Ne a végén kérd meg, hanem **menet közben**:

pl így:

```cpp
HANDLE hFind = FindFirstFile(searchPath.c_str(), &findFileData);
```

kérd meg hogy írja át így:

```cpp
// HANDLE = Windows resource handle (mint egy file pointer)
HANDLE hFind = FindFirstFile(searchPath.c_str(), &findFileData);

// FindFirstFile = első fájl keresése a directory-ban
```

Így gyorsabban tanul az agy.

# Ha könnyebbé akarod tenni magadnak:

Használhatsz ilyen naming trükköt:

Most:

```cpp
HANDLE hFind;
```

Tanulós verzió:

```cpp
HANDLE directoryHandle;
```

Most:

```cpp
WIN32_FIND_DATA findFileData;
```

Tanulós:

```cpp
WIN32_FIND_DATA fileInfo;
```

Ez brutál sokat segít megérteni.

---

# Egy nagyon hasznos trükk amit sok autodidakta dev használ:

Tanuló kommentek:

```cpp
// stat = file metadata lekérdezés (méret, típus stb)
struct stat path_stat;

// S_ISDIR = macro ami ellenőrzi hogy directory-e
entry.isDirectory = S_ISDIR(path_stat.st_mode);
```

Ez sokkal gyorsabb tanulás mint külön dokumentáció.

# Hogyan épül fel:

## 1️⃣ C standard library (régi alap)

Pl:

```
stat()
printf()
malloc()
fopen()
```

Ezek **C-ben vannak**, de C++ is tudja használni.

Doksi:
[https://en.cppreference.com](https://en.cppreference.com) → C library rész is van.

---

## 2️⃣ POSIX (Linux/Unix API)

Pl:

```
opendir()
readdir()
closedir()
stat()
```

Ez nem C standard, hanem **POSIX OS API**.

Doksi:
[https://man7.org/linux/man-pages/](https://man7.org/linux/man-pages/)

Nagyon jó példákkal.

Keress pl:

```
stat man page
opendir example
readdir example
```

---

## 3️⃣ Windows API

Pl:

```
FindFirstFile()
FindNextFile()
HANDLE
```

Ez Windows saját API.

Doksi:
Microsoft Learn:

[https://learn.microsoft.com](https://learn.microsoft.com)

Például:

```
FindFirstFile example
```
