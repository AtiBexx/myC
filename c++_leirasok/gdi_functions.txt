# Windows GDI (Graphics Device Interface) Függvények és Leírásuk

## 1. Régió (Region) Függvények

| Függvény | Leírás |
|----------|--------|
| CombineRgn | Két régiót kombinál és az eredményt egy harmadik régióban tárolja |
| CreateEllipticRgn | Elliptikus régiót hoz létre |
| CreateEllipticRgnIndirect | Elliptikus régiót hoz létre |
| CreatePolygonRgn | Sokszög régiót hoz létre |
| CreatePolyPolygonRgn | Több sokszögből álló régiót hoz létre |
| CreateRectRgn | Téglalapos régiót hoz létre |
| CreateRectRgnIndirect | Téglalapos régiót hoz létre |
| CreateRoundRectRgn | Kerekített sarkú téglalapos régiót hoz létre |
| EqualRgn | Megvizsgálja, hogy két régió azonos-e |
| ExtCreateRegion | Régiót hoz létre a megadott régióból és transzformációs adatokból |
| FillRgn | Kitölti a régiót a megadott ecsettel |
| FrameRgn | Keretet rajzol a megadott régió köré a megadott ecsettel |
| GetPolyFillMode | Lekéri a jelenlegi sokszög kitöltési módot |
| GetRegionData | A megadott puffert kitölti a régió leíró adataival |
| GetRgnBox | Lekéri a megadott régió határoló téglalapját |
| InvertRgn | Megfordítja a színeket a megadott régióban |
| OffsetRgn | Eltolja a régiót a megadott eltolásokkal |
| PaintRgn | Kifesti a megadott régiót az eszközkontextusban jelenleg kiválasztott ecsettel |
| PtInRegion | Meghatározza, hogy a megadott pont a régió belsejében van-e |
| RectInRegion | Meghatározza, hogy a megadott téglalap bármely része a régió határain belül van-e |
| SetPolyFillMode | Beállítja a sokszögek kitöltési módját |
| SetRectRgn | Egy régiót konvertál a megadott koordinátákkal rendelkező téglalapos régióvá |

## 2. Vonal- és Görberajzoló Függvények

| Függvény | Leírás |
|----------|--------|
| MoveTo | Beállítja az aktuális pozíciót a rajzolás előkészítéséhez |
| LineTo | Vonalat rajzol az aktuális pozícióból egy megadott pozícióba, és áthelyezi az aktuális pozíciót a vonal végére |
| Polyline | Pontok sorozatát köti össze vonalszakaszokkal |
| PolylineTo | Pontok sorozatát köti össze vonalszakaszokkal az aktuális pozícióból indulva, és áthelyezi az aktuális pozíciót a vonalzár végére |
| Arc | Ívet rajzol |
| ArcTo | Ívet rajzol és áthelyezi az aktuális pozíciót az ív végére |
| PolyBezier | Egy vagy több Bézier-görbét rajzol |
| PolyBezierTo | Egy vagy több Bézier-görbét rajzol és áthelyezi az aktuális pozíciót az utolsó görbe végére |
| PolyDraw | Vonalszakaszok és Bézier-görbék sorozatát rajzolja egy pontsorozaton keresztül, és áthelyezi az aktuális pozíciót az utolsó vonal vagy görbe végére |

## 3. Zárt Alakzatok Rajzolása

| Függvény | Leírás |
|----------|--------|
| Chord | Egy zárt alakzatot rajzol, amelyet egy ellipszis és egy egyenes metszete határol |
| Ellipse | Kört vagy ellipszist rajzol |
| Pie | Szeletes tortát (szeletes ívet) rajzol |
| Polygon | Pontok sorozatát köti össze egy sokszöggé |
| Rectangle | Téglalapot rajzol négyzetes sarkakkal |
| RoundRect | Téglalapot rajzol kerekített sarkakkal |

## 4. Szövegkezelő Függvények

| Függvény | Leírás |
|----------|--------|
| DrawText | Formázott szöveget rajzol egy téglalapba |
| DrawTextEx | Formázott szöveget rajzol egy téglalapba |
| TextOut | Egy sor szöveget ír ki az aktuális vagy megadott pozícióra |

| GetTextExtent | Kiszámítja egy karakterlánc szélességét az aktuális betűtípusban |
| GetTabbedTextExtent | Kiszámítja tabulátorokat tartalmazó karakterlánc szélességét az aktuális betűtípusban |
| GetTextMetrics | Betűmetrikákat ad vissza (karaktermagasság, átlagos karakter szélesség stb.) az aktuális betűtípushoz |
| SetTextAlign | Beállítja a szövegkiírási igazítási paramétereket |
| SetTextJustification | Megadja a szükséges plusz szélességet egy szöveg igazításához |
| SetTextColor | Beállítja az eszközkontextus szövegkiírási színét |
| SetBkColor | Beállítja az eszközkontextus háttérszínét, amely meghatározza a karakterek mögötti kitöltés színét |
