| Mit | Hogyan | Idő/nap |

| Mit | Hogyan | Idő/nap |
|---|---|---|
| **Word Power Made Easy** | Norman Lewis — szókincs latin/görög gyökerekből | 20 perc |
| **Tech olvasás** | Hacker News, dev.to, Wired naponta | 20 perc |
| **Speaking partner** | italki.com vagy Tandem app, natív partnerrel | 3x/hét |
| **GitHub angolul** | issues, PR-ok, README írása angolul | folyamatos |

### 3. fázis (18–36. hónap) — anyanyelvi írás

| Mit | Hogyan | Idő/nap |
|---|---|---|
| **The Elements of Style** | Strunk & White — rövid, klasszikus írásszabályok | 1x elolvasni |
| **Writing with Style** | John R. Trimble — egyetemi szintű fogalmazás | 30 perc |
| **The Atlantic / New Yorker** | havonta 4–5 hosszú cikk, figyeld a stílust | 30 perc |
| **Mock interjúk** | angolul, tech pozíciókra (rögzítsd magad) | hetente |

### Folyamatosan — minden nap

- Telefon és számítógép nyelve legyen **angol**
- **Anki** — napi 10–15 új szó kártyázás
- Gondolkodj angolul — belső monológok
- Angol zene hallgatás + szöveggel együtt olvasva

<a name="napi"></a>
## 2. Napi beosztás (1–2 óra)

```
Reggel   (20 perc)  →  Anki + podcast (menet közben is megy)
Délben   (30 perc)  →  Tankönyv vagy tech cikk olvasás
Este     (30–60 perc) →  Írás (napló) + speaking practice
```

> **A legfontosabb szabály:** Az anyanyelvi szint nem tankönyvből jön — a **mennyiségből** jön.
> Minél több angolt hallasz, olvasol és írsz naponta, annál gyorsabb a fejlődés.

<a name="igeidők"></a>
## 4. Igeidők — mikor mit

Ez a legnagyobb forrás a zűrzavarhoz. Íme a logika, nem csak a szabály.

---

### Will vs Going to — jövő idő

Sokan azt tanítják hogy mindkettő jövő. De más a funkciójuk.

**Will** → spontán döntés, ígéret, előrejelzés tény alapján

```
"I'll get the door."          → most döntöttem, spontán
"I'll help you tomorrow."     → ígéret
"It will rain tomorrow."      → előrejelzés (meteorológiai tény)
```

**Going to** → előre eltervezett szándék, látható jövő

```
"I'm going to study tonight." → már előre eldöntöttem
"She's going to have a baby." → látható, nyilvánvaló jövő
"We're going to move to the US." → terv, szándék
```

> **Ökölszabály:** Ha már előbb döntötted el → going to. Ha most, ebben a pillanatban → will.

---

### Present Simple vs Present Continuous

**Present Simple** → általános igazság, szokás, rendszeres cselekvés

```
"I work in tech."             → általában, ez a munkám
"Water boils at 100°C."       → mindig igaz
"She drinks coffee every day." → szokás
```

**Present Continuous (I am -ing)** → most zajlik, ideiglenes, tervezett jövő

```
"I'm working on a project."   → most, ebben a pillanatban
"I'm living in Budapest."     → ideiglenes (nem örökre)
"We're meeting tomorrow."     → konkrét, tervezett esemény
```

> **Fontos:** Vannak igék amelyek SOHA nem állhatnak continuous-ban:
> know, believe, want, need, love, hate, understand, seem, own

```
❌ "I'm knowing the answer."
✅ "I know the answer."
```

---

### Have been vs Have gone

Sokan felcserélik, pedig nagy a különbség.

**Have been** → voltam ott, de már visszajöttem

```
"I have been to New York."    → voltam ott (és most itt vagyok)
"She has been to the doctor." → járt orvosnál, már visszajött
```

**Have gone** → elment oda, és még ott van (vagy úton van)

```
"He has gone to New York."    → elment New Yorkba (még ott van)
"She has gone to the doctor." → orvoshoz ment (még ott van)
```

---

### Present Perfect vs Past Simple

Ez az egyik legtöbb hibát okozó különbség magyaroknak.

**Present Perfect (have + past participle)** → múltbeli esemény, amelynek **köze van a jelenhez**

```
"I have finished the project."    → most fejeztem be, friss
"Have you ever been to London?"   → általános élettapasztalat
"I've lost my keys."              → most vesztem el, most is elveszett
```

**Past Simple** → befejezett múltbeli esemény, **konkrét időpont**

```
"I finished the project yesterday." → tegnap, kész, múlt
"I went to London in 2019."         → konkrét időpont
"I lost my keys this morning."      → konkrét múlt
```

> **Ökölszabály:** Ha van konkrét időpont (yesterday, in 2019, last week) → Past Simple.
> Ha nincs időpont, csak "megtörtént valaha" → Present Perfect.

---

### Used to vs Would vs Past Simple

**Used to** → régen rendszeresen csináltam, de most már nem

```
"I used to play football."         → régen játszottam, most már nem
"She used to live in New York."    → régen ott élt, most már nem
```

**Would** → régi szokás (múltban ismétlődő cselekvés, de NEM állapot)

```
"Every summer, we would go to the lake." → szokásos nyári kirándulás
"He would always bring coffee."          → mindig hozta a kávét
```

> **Fontos különbség:** `would` NEM használható állapot igékkel!
> ```
> ❌ "I would live in New York." (állapot)
> ✅ "I used to live in New York."
> ```

**Past Simple** → egyszeri múltbeli esemény

```
"I played football yesterday."   → egyszer, tegnap
```

---

### Have been doing (Present Perfect Continuous)

Egy cselekvés a múltban **kezdődött** és **most is tart** vagy nemrég fejeződött be, és látszik az eredménye.

```
"I have been learning English for 2 years."  → 2 éve tanulom és még mindig tanulom
"She has been crying."                        → sírt (és a szeme még piros)
"I've been working all day."                  → egész nap dolgoztam (és fáradt vagyok)
```

---

### Összefoglaló táblázat

| Igeidő | Mikor | Példa |
|---|---|---|
| **Will** | spontán döntés, ígéret | "I'll call you." |
| **Going to** | előre tervezett szándék | "I'm going to call you later." |
| **Present Simple** | szokás, általános igazság | "I work in tech." |
| **Present Continuous** | most zajlik, ideiglenes | "I'm working on it." |
| **Past Simple** | befejezett múlt, konkrét idő | "I worked there in 2020." |
| **Present Perfect** | múlt + jelen kapcsolat | "I've worked there." |
| **Present Perfect Continuous** | múltban kezdődött, még tart | "I've been working here for 3 years." |
| **Used to** | régi szokás, már nem igaz | "I used to smoke." |
| **Would** | régi ismétlődő cselekvés | "We would go every summer." |

<a name="hallás"></a>
## 5. Hallás — miért nem érted elsőre

Ez a leggyakoribb probléma. Az oktatásban szép, lassú, tiszta kiejtést hallasz — az igazi beszéd egészen más.

### Mi történik a gyors beszédben

**1. Szavak összeolvadnak (linking)**

Az angolban ha egy szó mássalhangzóra végződik és a következő magánhangzóval kezdődik, összeolvadnak:

```
"turn it off"   →  "tur-ni-toff"
"pick it up"    →  "pi-ki-tup"
"did you"       →  "didju"
"want to"       →  "wanna"
"going to"      →  "gonna"
"have to"       →  "hafta"
"don't know"    →  "dunno"
"kind of"       →  "kinda"
"out of"        →  "outta"
```

**2. Hangsúlytalan szótagok "elnyelődnek"**

Az angolban csak a **hangsúlyos szótagot** ejtik tisztán, a hangsúlytalan szótagok egy semleges hangra redukálódnak (ezt hívják "schwa"-nak, jele: ə):

```
"probably"   →  "prob-bly" (az 'a' és 'b' eltűnik)
"family"     →  "fam-ly"
"comfortable" → "comf-ter-ble"
"vegetable"  →  "vej-tbl"
"interesting" → "int-resting"
```

**3. T hang eltűnik vagy "D" lesz**

Amerikaiban a T hang szó közepén "D"-nek hangzik (ezt hívják flap T-nek):

```
"water"   →  "wader"
"better"  →  "bedder"
"butter"  →  "budder"
"little"  →  "lidle"
"city"    →  "siddy"
```

**4. H hang eltűnik**

```
"What does he want?"  →  "What does 'e want?"
"Tell him"            →  "Tell 'im"
```

### Mit tegyél ellene

- Hallgass **sok természetes, gyors** angol beszédet — nem tankönyves, hanem igazi (sorozatok, podcastok)
- Amikor nem értesz valamit, ne azonnal nézd meg a feliratot — próbáld meg 2–3x
- Használd a **Language Reactor**-t: megállítja és mutatja a szót
- Shadowing technika: hallgatsz egy mondatot, majd megismétled ugyanolyan tempóban és hangsúllyal

<a name="keverés"></a>
## 6. Hasonló hangzású szavak — ne keverd össze

### Bowl vs Bool (pool)

```
bowl  /boʊl/  →  az "o" hosszú, mint "bó-l"  →  tál, labda-szerű tárgy
pool  /puːl/  →  az "oo" hosszú, mint "pú-l"  →  medence, pool
```

> Tipp: a bowl-ban az ajkad kerekíted mint az "ó"-nál, a pool-ban mint az "ú"-nál.

### Eat vs It

```
eat  /iːt/  →  hosszú "í", mint "í-t"  →  enni
it   /ɪt/   →  rövid, laza "i"         →  az, azt
```

> Ha valaki gyorsan mondja: a kontextus mindig segít. "I eat lunch" vs "I it lunch" — az utóbbi értelmetlen.

### Need vs Ned

```
need  /niːd/  →  hosszú "í"  →  szükségem van
ned          →  tulajdonnév (becenév)
```

### Ship vs Sheep

```
ship   /ʃɪp/  →  rövid "i"  →  hajó
sheep  /ʃiːp/ →  hosszú "í" →  juh
```

### Live vs Leave

```
live   /lɪv/  →  rövid "i"  →  élni (I live here)
leave  /liːv/ →  hosszú "í" →  elmenni, elhagyni
```

### Általános szabály a magánhangzókhoz

| Rövid | Hosszú | Különbség |
|---|---|---|
| /ɪ/ — "i" mint "bit" | /iː/ — "í" mint "beat" | ship / sheep |
| /ʊ/ — "u" mint "book" | /uː/ — "ú" mint "boot" | full / fool |
| /æ/ — "a" mint "cat" | /eɪ/ — "é" mint "cake" | man / mane |

> **Legjobb gyakorlat:** Minimal pairs — olyan szópárokat hallgatsz ahol csak 1 hang különbözik. YouTube: "minimal pairs listening practice"

<a name="szórend"></a>
## 7. Szórend — miért van a normally előrébb

### A kérdés: "People don't normally come to this room"

Miért nem: "People don't come normally to this room"?

Az angolban a **határozószók (adverbs of frequency)** — always, usually, normally, often, sometimes, rarely, never — **sajátos helyet foglalnak el a mondatban**.

### A szabály

**Segédige előtt, főige előtt, de a "to be" után:**

```
She    always    arrives    early.
       ↑
    (főige előtt)

He     is        always     late.
                 ↑
           (to be után)

I      don't     normally   go    there.
               ↑
        (segédige után)
```

### Miért?

Az angolban a határozószó az igéhez kapcsolódik szorosan — azt módosítja. Ezért nem kerülhet a mondat végére (bár informálisan néha igen), és nem kerülhet az alany elé (kivéve: sometimes az elején is állhat hangsúlyosan).

```
✅ "People don't normally come here."     → természetes
✅ "People normally don't come here."     → hangsúlyos, de helyes
❌ "People don't come normally here."     → természetellenes
❌ "Normally people don't come here."     → helyes, de hangsúlyos/formális
```

### Még néhány példa

```
"I usually wake up at 7."         ✅  (főige előtt)
"I am usually tired."             ✅  (to be után)
"She has never been to Paris."    ✅  (have + past: a never a past participle előtt)
"He will probably call."          ✅  (will + határozószó + főige)
"Sometimes I forget."             ✅  (mondat elején — megengedett)
```

### Más típusú határozószók helye

Nem csak a frekvencia-határozószók követnek szabályt:

| Típus | Hely | Példa |
|---|---|---|
| Frekvencia (always, never...) | főige előtt / to be után | "She always smiles." |
| Mód (quickly, slowly...) | ige után vagy mondat végén | "He ran quickly." |
| Hely (here, there...) | mondat végén | "She lives there." |
| Idő (yesterday, now...) | mondat elején vagy végén | "Yesterday I saw him." |

## Végszó

Az anyanyelvi szint nem egy nap alatt jön el — de ha minden nap csinálod, 2–3 éven belül elérhető. A legfontosabb az, hogy **ne tanulj angolul, hanem éljél angolul** — nézz sorozatokat, olvass cikkeket, írj naplót, gondolkodj angolul. A nyelvtant a fül tanulja meg, nem az elme.
